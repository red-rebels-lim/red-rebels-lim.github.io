# Red Rebels — Flutter app

Native Android & iOS companion to the Red Rebels Calendar web app (`../app`).
Same data, same i18n bundles, same stats logic — ported to Dart.

## Features

- **Calendar** — season month grid (Sep 2025 → Aug 2026) with swipe navigation,
  list view toggle, sport/location/status/opponent filters, next-match countdown
  banner, and a match details sheet (score, scorers, bookings, subs, volleyball
  sets & top scorers).
- **Statistics** — three tabs: Men's Football (league-only, mirrors
  `app/src/lib/stats.ts`), Men's & Women's Volleyball (mirrors
  `app/src/lib/volleyball-stats.ts`).
- **Settings** — English/Greek language toggle and system/light/dark theme,
  persisted with `shared_preferences`.

## Data flow

Match data is **not** hand-maintained here. `assets/data/events.json` is
generated from the web app's `app/src/data/events.ts` (itself generated by the
scraper):

```bash
node tool/generate_events_json.mjs
```

Re-run that after every scraper run / `events.ts` change, then rebuild.
The i18n bundles (`assets/i18n/{en,el}.json`) are copies of
`app/src/i18n/*.json`, and team logos are copies of
`app/public/images/team_logos/*.webp` — re-copy if they change upstream.

The Greek→English team/venue lookup maps live in `lib/data/constants.dart`
and mirror `app/src/lib/translate.ts`. A new opponent upstream means updating
those maps too (see the root `CLAUDE.md` "Adding a new opponent").

## Build & run

```bash
flutter pub get
flutter run                      # debug on a connected device/simulator
flutter test                     # widget tests
flutter build apk --release      # Android
flutter build ipa --release      # iOS (requires signing setup in Xcode)
```

Bundle IDs: `com.redrebels.red_rebels_calendar` (both platforms).

## Layout

```
lib/
  main.dart                 # entry point, bottom-nav shell
  theme.dart                # brand red #E02520, sport/result colours
  models/events.dart        # SportEvent etc. (port of types/events.ts)
  data/constants.dart       # season config, month math, translation maps
  data/events_repository.dart
  i18n/i18n.dart            # JSON-bundle lookup (port of i18next usage)
  state/app_state.dart      # language/theme/filters (provider)
  logic/football_stats.dart # port of lib/stats.ts
  logic/volleyball_stats.dart
  pages/                    # calendar, stats, settings
  widgets/                  # event card, details sheet, team logo
tool/generate_events_json.mjs
assets/{data,i18n,images}
```
